Repository description

Share your Windows mouse and keyboard with iPad over Bluetooth LE HID. 9 UI languages. Dedicated USB adapter required. MIT; based on fuba/winuc.

Facts for release notes

Glideleaf is an independent derivative of fuba/winuc. It uses a dedicated USB Bluetooth adapter and WinUSB to forward BLE HID input to iPad. No iPad app or cloud relay is required. Clipboard sharing, file transfer and screen mirroring are not implemented. Physical device and installer qualification remain pending.
