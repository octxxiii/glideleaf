# Glideleaf v0.2.0-alpha.1 — Windows portable preview

This is an **unsigned alpha prerelease**, not a production-ready installer.
It is a portable Windows x64 build of the independently maintained
[fuba/winuc](https://github.com/fuba/winuc) derivative. Thanks to fuba for
creating and sharing WinUC under MIT.

## Download and start

1. Download `Glideleaf-0.2.0-alpha.1-win-x64.zip` from this release and verify
   the SHA-256 value in the companion `SHA256SUMS.txt` asset if desired.
2. Extract the complete `Glideleaf` folder. Keep `_internal` next to
   `Glideleaf.exe`; no Python installation is needed.
3. Run `Glideleaf.exe`, select a **dedicated compatible USB Bluetooth adapter**
   in **Adapter setup / restore**, and approve the Windows administrator prompt
   if you choose to change that adapter to WinUSB.
4. Start the connection, pair **Windows Pointer & Keyboard** in iPadOS Bluetooth
   settings, and arrange the screens in **Pointer & keyboard → Screen layout**.

The app can restore the selected adapter's normal Bluetooth driver from the
setup screen. An adapter bound to WinUSB cannot serve ordinary Windows
Bluetooth devices at the same time. Do not use your only keyboard/mouse radio.

## Included changes

- Native Windows inbox WinUSB setup without Zadig or wdi-simple.
- Explicit USB adapter selection, diagnostics and driver restoration.
- Drag-to-arrange iPad position and an adjustable crossing segment.
- Polished 1366×768 desktop layout, generated icon and nine UI languages.
- BLE mouse/keyboard forwarding, tray status and emergency return shortcut.

## Known limits

- The executable is **unsigned**. Windows or a managed-PC security policy may
  decline it; the app does not bypass those policies.
- A user reported a successful CSR dongle connection on another PC, but the
  exact hardware and sustained input, restart and restore observations are not
  documented. Other dongles are not certified by this prerelease.
- Realtek firmware is not bundled. If your adapter needs firmware, follow the
  source setup instructions in the README; the portable build does not fetch it.
- No shared clipboard, file transfer, screen mirroring or built-in Bluetooth
  radio support is claimed. This is not Apple's Continuity protocol.
- Clean-machine install, UAC under a different administrator account,
  sleep/resume and long-session input remain to be verified.
